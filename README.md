# 개인 목표
### 프리코스로부터 원하는 보상
저는 처음 마주하는 문제를 빠르게 해결하는 실전 능력을 기르고 싶습니다. 그리고 그러한 적응력을 갖춘 엔지니어가 되고 싶습니다.

매 문제마다 효과적으로 경험을 축적하는 시스템을 만들어, 앞으로의 팀 프로젝트나 개인 챌린지에서 빠르고 효율적으로 학습하고 실행하는 것이 저의 목표입니다.

> 💡 프리코스를 통해 얻고자 하는 것 <br>최소 규모의 애플리케이션을 만들고, 점진적인 학습을 통해 성장을 가속화하는 방법을 터득한다.


### 개발 학습 패턴
저의 개발 방식을 되돌아보니, 무의식적으로 다음과 같은 패턴을 따르고 있었습니다:

> '처음 보는 것 → 최소 스코프 학습 → 적용 → 넓은 스코프 확장 학습 → 재적용' 

이러한 패턴을 의식화하고 집중적으로 훈련하기 위해, 제 학습 시스템을 프로세스화했습니다.

### 과제 진행 요구사항
- 1. README.md에 기능 목록 ToDoList를 작성한다.
- 2. 커밋 단위는 README.md에 정리한 기능 목록 단위로 추가한다.
- 3. AngularJS Git Commit Message Conventions 을 참고하면 좋다.
- 4. 기능 요구 사항에 기재되지 않은 내용은 스스로 판단하여 구현한다.

### 프로그래밍 요구사항
- 자바 코드 컨벤션 Java Style Guide를 지킨다.
- 프로그램 종료 시 System.exit()를 호출하지 않는다.
- build.gradle 파일은 변경할 수 없으며, 제공된 라이브러리 이외의 외부 라이브러리는 사용하지 않는다.
